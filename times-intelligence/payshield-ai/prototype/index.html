PayShield AILocal prototype · synthetic data · company ACO (tenant A)

1Train the company model

Uses only this company's payroll history. Isolation Forest is compared with a robust statistical baseline on the latest months with injected anomalies; the better one is activated if it passes the gate.

2Create a test pay run

Adds a new month for all employees with known problems injected for a few of them (dev-only helper).

3Analyse the pay run

Rules + model score each employee against their own history. Risk score is a priority rank, not a probability.

4Ask the assistant

Read-only; employees appear as pseudonyms. With no Azure OpenAI configured it answers deterministically.
